# 零碳厨房共创征集 · 稳定托管部署指南

**目标：把当前运行在临时随机链接上的整套站点（征集页 + 表单后端 + 管理后台）迁移到长期稳定地址，公众号文章发布后链接永不失效。**

项目已完成生产化改造：`npm start` 即可启动一体化服务（前端静态 + `/api` 后端 + 数据落盘）。以下三条路径任选其一。

---

## 路径 A：国内云服务器（最推荐 · 公众号读者访问最快）

适合：您或机构已有阿里云 / 腾讯云 / 华为云服务器（轻量应用服务器即可，约 50—100 元/年）。

**把以下信息交给 AI 或技术同事，全程自动执行：**
1. 服务器公网 IP；2. SSH 用户名与私钥（或密码）；3. （可选）已备案域名。

**服务器上只需 4 条命令（Ubuntu/Debian 示例）：**

```bash
# 1. 安装 Node 20 与 PM2
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash - && sudo apt install -y nodejs
sudo npm i -g pm2

# 2. 上传项目（本地执行：scp -r zero-carbon-kitchen-site 用户@IP:/opt/zc-kitchen）

# 3. 构建并启动
cd /opt/zc-kitchen && npm ci && npm run build
ADMIN_KEY=换成强密钥 pm2 start ecosystem.config.cjs && pm2 save && pm2 startup

# 4. 防火墙放行 8787 端口（或配置 Nginx/Caddy 反代到 80/443）
```

完成后地址为 `http://服务器IP:8787`（或绑定的域名）。管理后台在 `/admin`。

---

## 路径 B：Docker 一键部署（任何支持 Docker 的主机 / 容器平台）

适合：服务器已有 Docker，或使用 阿里云容器服务 / 腾讯云 TKE / Sealos / Railway / Render 等。

```bash
docker build -t zc-kitchen .
docker run -d --name zc-kitchen --restart unless-stopped \
  -p 80:8080 \
  -v zc-data:/app/server/data \
  -e ADMIN_KEY=换成强密钥 \
  zc-kitchen
```

数据持久化在名为 `zc-data` 的卷中（`server/data/submissions.jsonl`），容器重建不丢数据。

---

## 路径 C：免费托管平台（零成本 · 需注册一个账号）

适合：无服务器预算。推荐 **Cloudflare（Pages + Workers）或 Vercel**，注册免费账号后把凭证（API Token）交给 AI，由其完成改造与部署。

- ⚠️ **中国大陆可达性提示**：`*.vercel.app` 在大陆访问不稳定，公众号读者多为国内用户，**不建议 Vercel**；Cloudflare 的 `*.pages.dev` 相对可用但仍不及国内服务器。
- 表单后端需改造为平台对应的 Serverless Functions（约 30 分钟工作量，AI 可完成）。
- 若使用国内平台的"云开发"（腾讯云 CloudBase / 阿里云 EMAS），访问最快且自带数据库，同样需账号。

---

## 迁移后的收尾动作（AI 执行）

1. 用稳定地址重新生成两枚二维码，重新合成图5征集卡；
2. 更新发布执行稿中的全部链接；
3. 清空管理后台测试数据，全链路回归验证（提交 → 后台可见 → CSV 导出）。

## 数据与安全约定

- 管理密钥（ADMIN_KEY）只保存在服务器环境变量或 `server/admin-key.txt`，**不进入任何公开文档**；
- 提交数据（含联系方式）仅存于服务器本地 `server/data/`，不出机房；
- 建议管理后台仅在办公网络访问，或在反向代理层再加一层 IP 白名单。
